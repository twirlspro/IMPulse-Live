**IMPulse Live** — умный оверлей-ассистент для стадии драфта Dota 2. Приложение сканирует экран в реальном времени, мгновенно распознает пики обеих команд и вычисляет оптимальные рекомендации на основе байесовской модели, актуальной меты и вашей персональной статистики.

---

## 🌟 Основные возможности

- 👁️ **Автораспознавание драфта**: компьютерное зрение на базе OpenCV детектирует героев союзников и оппонентов на лету.
- 🧠 **Математическая модель драфта**:
  - Расчет контрпиков против врагов (`Cnt`) и синергий с союзниками (`Syn`).
  - Учет персональной статистики игрока (винрейт, опыт, наигрыш на конкретных ролях).
  - Срезы по рангам: *Все*, *Archon+*, *Ancient+*, *Divine+*.
  - Настраиваемые фильтры популярности (пикрейт), опыта («Знакомые», «Основные») и актуальности по патчам.
- 🪟 **Эргономичный оверлей**:
  - Работает поверх игры (рекомендуется режим Dota 2 *«В окне без рамки»*).
  - Моментальное скрытие / показ по нажатию горячей клавиши (по умолчанию `Insert`).
  - Свободное перетаскивание зажатием ЛКМ в любом месте окна.
  - Работа в фоне через системный трей возле часов Windows.
- 🛡️ **100% VAC Safe**: приложение никак не взаимодействует с памятью процесса Dota 2 и работает исключительно через захват изображения экрана.

## 🚀 Быстрый старт

1. Скачайте архив репозитория (**[Download ZIP](https://github.com/twirlspro/IMPulse-Live/archive/refs/heads/main.zip)**) или склонируйте его:
   ```bash
   git clone https://github.com/twirlspro/IMPulse-Live.git
   ```
2. Откройте папку и запустите **`IMPulseLive.exe`**.
3. *(Опционально)* Нажмите шестеренку (⚙️) и укажите свой **Steam ID**, затем нажмите **«Синхронизировать»** для загрузки персональной статистики.
4. На стадии выбора героев в Dota 2 окно автоматически отобразит лучшие варианты для вашего пика.

## ⌨️ Управление и горячие клавиши

| Действие | Управление |
| :--- | :--- |
| **Показать / Скрыть оверлей** | Клавиша `Insert` *(можно переназначить в настройках)* |
| **Перемещение окна** | Зажмите левую кнопку мыши в любом месте окна |
| **Системный трей** | Клик по иконке в трее открывает меню или переключает видимость |
